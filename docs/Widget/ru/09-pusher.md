# Pusher

Класс `Pusher` отвечает за инициализацию Laravel Echo и подписку на все real-time события виджета.

---

## Инициализация

Запускается при старте виджета. Создаёт единственное соединение и сохраняет его глобально — повторная инициализация при уже существующем соединении игнорируется.

Канал виджета: `uplify.ads.{slug}`

Авторизация приватного канала — POST-запрос на `{API_URL}/broadcasting/auth` с `socket_id`, `channel_name`, `slug`.

---

## Публичный канал

```
channel: uplify.ads.{slug}
```

| Событие | Описание |
|---|---|
| `.pusher:subscription_count` | Отслеживает количество активных вкладок с виджетом |

Если открыто больше одной вкладки — API-запросы и отправка чат-сообщений блокируются (работает только одна копия).

---

## Приватный канал

```
private channel: private-uplify.ads.{slug}
```

### При подключении

| Событие | Описание |
|---|---|
| `.pusher:subscription_succeeded` | Отправляет данные текущей сессии в отладочный инструмент |

### Настройки виджета

| Событие | Описание |
|---|---|
| `.widget.params.updated` | Обновляет настройки виджета «на лету» без перезагрузки страницы |
| `.widget.refresh` | Перезагружает страницу виджета |

### Реклама

| Событие | Описание |
|---|---|
| `.auto.launch` | Получает пакет креативов для показа и сбрасывает таймер следующего запроса; проверяет версию виджета |
| `.manual.launch` | Запускает немедленный показ рекламы из очереди (ручной режим) |

### Демо-режим

| Событие | Описание |
|---|---|
| `.demo.real.launch` | Запускает демо-показ с реальными рекламными кампаниями (из раздела дебага в ЛК стримера/партнёра) |
| `.demo.launch` | Запускает тестовый демо-показ |
| `.demo.referral.launch` | Запускает реферальный демо-показ |

### Прочее

| Событие | Описание |
|---|---|
| `.chatbot.disconnected` | Отключает чатбот — UI показывает предупреждение |
| `.conversion.alert.approved` | Показывает уведомление о конверсии |

### Закомментировано

`.referral.launch` — реферальная реклама. Логика присутствует в коде, но отключена.

## Debug-события (клиентские whisper)

Используются отладочным инструментом. Слушаются на приватном канале как `.client-{name}`.

| Событие | Описание |
|---|---|
| `.client-debugger.connection` | Читает текущие настройки OBS и отправляет их в дебаггер |
| `.client-obs.settings.defaults` | Применяет настройки OBS по умолчанию |
| `.client-obs.settings.custom` | Применяет переданные кастомные настройки OBS |
| `.client-widget.refresh` | Перезагружает страницу виджета |
| `.client-ping.sessions` | Отправляет данные текущей сессии в дебаггер |
| `.client-delete.session` | Закрывает OBS-слой для указанной сессии |

---

## Проверка версии

Происходит при каждом получении рекламы. Если версия виджета изменилась с момента последнего запроса — страница перезагружается (деплой нового кода).
