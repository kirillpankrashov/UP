# Impression Pixels

Пиксели — URL-ссылки для отслеживания показов и кликов, которые партнёр настраивает на уровне креатива. Виджет вызывает их в момент воспроизведения рекламы.

---

## Типы пикселей

### Impression pixels (`creative.pixels.impressions`)

Стандартные пиксели показа, настроенные партнёром в адсете. Применяются для форматов: `FULLSCREEN`, `PIP`, `CUSTOM`, `CPMSTAR_BANNER`.

Вызываются при монтировании компонента: каждый URL вставляется в DOM как `<img width="1" height="1">`.

### SSP impression pixels (`extend.pixel_impressions`)

Отдельный набор пикселей, возвращаемых SSP или CPMStar API при подготовке креатива. Применяются для форматов: `YANDEX_FS`, `YANDEX_PF`, `YANDEX_TEXT`, `CPMSTAR_BANNER`.

Вызываются аналогично — 1×1 img-тегами при монтировании.

### Click pixels (`creative.pixels.clicks`)

Пиксели кликов виджет **не вызывает напрямую**. Они передаются в SSP-сообщение чатбота (`pixel_clicks`) и обрабатываются на стороне бекенда при переходе пользователя по ссылке.

---

## Макросы в URL

Перед вставкой пиксели обрабатываются — в URL заменяются макросы:

| Макрос | Значение |
|---|---|
| `{{viewers}}` | Количество зрителей стрима в момент показа (`viewersCount`) |
| `{{random}}` | Случайная 10-символьная строка — для предотвращения кэширования |

---

## Механизм вставки

Каждый пиксель вставляется как `<img>` с уникальным `id` в DOM-элемент компонента. Если пиксель с таким `id` уже существует — он удаляется перед повторной вставкой (защита от дублирования при переключении креативов).
