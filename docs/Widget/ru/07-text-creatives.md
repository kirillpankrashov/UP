# Текстовые форматы

К текстовым относятся два формата: `YANDEX_TEXT` и `CHATBOT_TEXT`. Оба не имеют визуального отображения — реклама доставляется как сообщение в чат стримера через бекенд (Nightbot).

---

## Место в adSet

Порядок определяется сервером. Текстовые форматы, как правило, идут **после медиа-креативов** в том же пакете.

Пример adSet: `[FULLSCREEN, YANDEX_TEXT, CHATBOT_TEXT]`

---

## Фильтрация

Оба формата не добавляются в очередь при включённом режиме низкой частоты (`isLowFrequency`). `YANDEX_TEXT` дополнительно пропускается, если SSP Text API не вернул результат.

---

## Задержки перед отправкой

После завершения медиа-рекламы виджет визуально пропадает, а текстовые форматы продолжают обрабатываться в фоне. Перед отправкой каждого сообщения выдерживается пауза:

| Формат | Задержка |
|---|---|
| `YANDEX_TEXT` | 7 / 5 / 3.3 мин (настройка `sspTextFrequency`) |
| `CHATBOT_TEXT` | 5 мин (фиксированно) |

Помимо этого, отправка учитывает задержку трансляции стримера (`stream.delay`) — чтобы сообщение появилось в чате синхронно с рекламой на экране.

---

## Отправка сообщения

Сообщение не отправляется если открыто несколько вкладок с виджетом (только одна копия работает одновременно).

`YANDEX_TEXT` передаёт в сообщение данные из SSP-ответа: текст, ссылку, пиксели кликов. Для `CHATBOT_TEXT` текст сообщения формирует бекенд на основе `impressionSlug`.

При ошибке — одна повторная попытка через 45 секунд.

---

## Отличия YANDEX_TEXT от CHATBOT_TEXT

| | `YANDEX_TEXT` | `CHATBOT_TEXT` |
|---|---|---|
| Задержка | 7 / 5 / 3.3 мин | 5 мин |
| Impression-пиксели | есть | нет |
| Текст сообщения | из SSP-ответа | формирует бекенд |
| Внешний запрос при подготовке | SSP Text API | нет |

---

## Таймлайн примера

`[FULLSCREEN (30 сек), YANDEX_TEXT, CHATBOT_TEXT]`, `sspTextFrequency = 2`

| Время | Событие |
|---|---|
| t=0 | Интро 20 сек |
| t=+20 сек | Воспроизведение FULLSCREEN |
| t=+50 сек | FULLSCREEN завершён, виджет скрыт |
| t=+50 сек | Пауза 5 мин перед YANDEX_TEXT |
| t=+5 мин 50 сек | Сообщение YANDEX_TEXT отправлено в чат |
| t=+5 мин 53 сек | Пауза 5 мин перед CHATBOT_TEXT |
| t=+10 мин 53 сек | Сообщение CHATBOT_TEXT отправлено в чат |
| t=+10 мин 56 сек | Пакет завершён |
