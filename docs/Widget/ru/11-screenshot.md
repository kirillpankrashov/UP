# Screenshot

Класс `Screenshot` фиксирует факт показа рекламы — отправляет запрос к сервису скриншотов после начала воспроизведения каждого медиа-креатива (текстовые форматы пропускаются).

---

## Когда отправляется

Запрос делается при двух сценариях:

1. **Первый час работы виджета** — после инициализации скриншоты включаются автоматически на 1 час
2. **Флаг `makeScreenshots` на адсете** — партнёр может принудительно включить скриншоты для конкретного адсета независимо от временного окна

Отправка откладывается на **8 секунд** после старта воспроизведения, чтобы OBS успел зафиксировать показ.

Демо-показы и ситуации с несколькими открытыми вкладками виджета не скриншотируются.

---

## Что передаётся

Платформа стримера + идентификаторы показа: `impressionSlug` и `creative.slug`. Для YouTube дополнительно передаётся `stream_info.id` вместо никнейма.

При ошибке — одна повторная попытка через 45 секунд.
