# Кампании — Система таблиц

Раздел содержит 13 таблиц — по одной на каждую комбинацию типа кампании и уровня сущности. Все таблицы используют единый паттерн загрузки, пагинации и настройки видимости. Набор колонок по типам кампаний описан в [02-campaign-types.md](./02-campaign-types.md).

---

## Настройка видимости колонок

В правой части таблицы есть колонка с иконкой фильтра. Клик открывает popover со списком чекбоксов — по одному на каждую переключаемую колонку. Колонки **ID** и **Name** всегда видимы.

Настройки сохраняются в `localStorage` и применяются при следующем открытии. Каждая таблица имеет свой набор значений по умолчанию.

---

## Пагинация

Все таблицы пагинированы: размер страницы определяется API, текущая страница берётся из URL query-параметра `page`. При одной странице пагинация скрыта. Смена страницы обновляет URL и перезагружает данные.

---

## Состояния загрузки

| Состояние | Что отображается |
|---|---|
| Первая загрузка | Skeleton-заглушка таблицы |
| Последующие загрузки | Индикатор загрузки поверх контента |
| Пустой список | Текст «Вы ещё не создали ни одной кампании» |
| Ошибка | Логируется; специального UI нет |

> Skeleton-заглушки учитывают текущие настройки видимости колонок — плейсхолдеры рендерятся только для видимых колонок.
