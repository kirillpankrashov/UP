# Кампании — Статусы и действия

Из списка кампаний доступно ограниченное количество действий: переключение видимости, создание, редактирование и переход к аналитике.

---

## Статусные поля

| Поле | Назначение |
|---|---|
| `visible` | Включена/выключена сущность. Единственный статус, управляемый из списка |
| `closed` | Кампания заблокирована системой. Нельзя включить из интерфейса |
| `published` | Прошла ли модерация |

### Переключатель статуса

Колонка Status отображает переключатель On / Off. При переключении отправляется запрос на сервер; при успехе статус обновляется локально. Кеш списков инвалидируется.

### Когда переключатель заблокирован

| Уровень | Условие блокировки |
|---|---|
| Кампания | Кампания закрыта (`closed`) |
| Группа | Родительская кампания выключена |
| Креатив | Родительская группа или кампания выключена |

При наведении на заблокированный переключатель появляется подсказка с причиной:
- «Выключен родитель» — для групп и креативов
- «Обратитесь в поддержку для включения» — для закрытых кампаний

### Модерация

Колонка Moderation показывает текстовый статус:
- «Пройдена» (зелёный) или «В процессе» (оранжевый)

Модерация не управляется из списка — это информационная колонка.

---

## Создание

Кнопка создания меняет поведение в зависимости от текущей вкладки:

| Вкладка | Действие |
|---|---|
| Кампании | Переход на страницу создания кампании |
| Группы | Открытие drawer'а для выбора кампании, затем переход на создание группы |
| Креативы | Открытие drawer'а для выбора группы, затем переход на создание креатива |

### Sidebar-панели

**CampaignsSidebar** — drawer с пагинированным списком кампаний текущего типа. При выборе строки — переход на создание группы.

**AdsetsSidebar** — аналогичный drawer со списком групп. При выборе — переход на создание креатива.

Sidebar-панели загружают данные независимо от фильтров основной таблицы.

---

## Редактирование

Колонки ID и Name — ссылки на страницы редактирования соответствующей сущности (кампании, группы или креатива).

---

## Аналитика

На каждой строке таблицы отображается иконка графика. Клик ведёт на страницу аналитики с датами кампании. Для групп и креативов аналитика открывается в контексте родительской кампании с переходом на вкладку креативов.

> У Special Project аналитика отключена.

---

## Нереализованные действия

В локалях определены ключи для действий «Дублировать», «Удалить» и «Скачать отчёт», но они не привязаны к UI в текущей версии.
