# Кампании — Обзор

## Что это

Раздел «Кампании» — центральный экран партнёрского кабинета для управления рекламными сущностями: кампаниями, группами (ad sets) и креативами. Все пять типов кампаний отображаются единым интерфейсом — пагинированная таблица с поиском, фильтрами и переключателем уровня сущностей.

## Иерархия сущностей

```
Campaign
 └── Ad Set (группа)
      └── Creative (креатив)
```

Каждая сущность привязана к родителю: группа принадлежит кампании, креатив — группе. Статус дочерней сущности зависит от статуса родителя (подробнее в [05-status-and-actions.md](./05-status-and-actions.md)).

## Типы кампаний

| Тип | Вкладки | Заголовок в UI |
|---|---|---|
| Brand Awareness | Кампании, Группы, Креативы | Спонсорские кампании |
| Performance | Кампании, Группы | Интерактивные кампании |
| Preroll | Кампании, Группы | Preroll кампании |
| Extension | Кампании, Группы, Креативы | Расширенные кампании |
| Special Project | Кампании, Группы, Креативы | Спецпроекты кампании |

> Performance и Preroll не имеют вкладки «Креативы».

Подробнее о различиях типов — в [02-campaign-types.md](./02-campaign-types.md).

## Структура экрана

Один компонент `Campaigns.vue` обслуживает все маршруты. На экране:

- **Переключатель вкладок** — Кампании / Группы / Креативы (набор зависит от типа кампании)
- **Поиск** — по имени или slug
- **Фильтры** — статус, платформа, рекламодатель
- **Кнопка создания** — создание кампании, группы или креатива
- **Таблица** — подбирается по типу кампании и уровню сущности (13 вариантов)
- **Sidebar-панели** — drawer'ы для выбора родительской сущности при создании группы или креатива

Тип кампании и уровень сущности определяются текущим маршрутом. Маршрут по умолчанию (`/`) ведёт на Brand Awareness → Кампании.

## Поток данных

Единственный Pinia-стор `useCampaignsStore` хранит три коллекции — `campaigns`, `adsets`, `creatives` — с данными для таблицы (список элементов, общее количество, размер страницы, флаги загрузки).

При смене маршрута, страницы, поиска или фильтра стор загружает данные из API (`GET partner/campaigns/{type}[/{entity}]`), записывает их в нужную коллекцию, и таблица отображает результат. API-ответы кешируются на 1 час.
