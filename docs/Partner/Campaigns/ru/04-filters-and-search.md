# Кампании — Фильтры и поиск

Поиск и фильтрация работают через URL query-параметры. При любом изменении данные перезагружаются из API.

---

## Поиск

Текстовое поле с задержкой 600 мс. Поддерживает два режима:

- **По имени** — обычный текст передаётся как параметр `name`
- **По slug** — если введённое значение распознаётся как slug кампании, передаётся как параметр `slug`

При изменении поиска страница сбрасывается на первую.

---

## Фильтры

Три фильтра, каждый добавляется через popover «Добавить фильтр»:

| Фильтр | Описание | Доступность |
|---|---|---|
| Status | Включена/выключена сущность | Всегда |
| Platform | Twitch, YouTube, Trovo, VK Play | Только на вкладке «Группы» |
| Advertiser | Выбор рекламодателя из списка | Всегда |

### Поведение

- Если в URL уже есть параметр фильтра — фильтр отображается автоматически при загрузке страницы.
- При переключении вкладок доступность фильтров пересчитывается: Platform доступен только для групп.
- Каждый фильтр можно закрыть кнопкой — при этом параметр очищается из URL.
- Если все фильтры уже активны, кнопка «Добавить фильтр» скрывается.

> Sidebar-панели (при создании групп и креативов) загружают данные независимо от фильтров основной таблицы — передаётся только номер страницы.
