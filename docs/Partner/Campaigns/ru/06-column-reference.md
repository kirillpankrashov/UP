# Кампании — Справочник колонок

Описание каждой колонки таблиц раздела «Кампании». Сводная матрица «есть / нет» по типам — в [типах кампаний](./02-campaign-types.md). Настройка видимости — в [системе таблиц](./03-table-system.md).

---

## ID

Slug сущности, оформленный как ссылка. Клик ведёт на экран редактирования (кампании, группы или креатива). Колонка **фиксирована** — не прокручивается горизонтально. Всегда видима, не отключается.

**Таблицы:** все.

---

## Name

Название сущности (`title.default`), оформленное как ссылка на экран редактирования — тот же маршрут, что у ID. Всегда видима, не отключается.

**Таблицы:** все.

---

## Status

Переключатель **вкл./выкл.** (`ElSwitch`). Изменение вызывает API `toggleStatus`.

Переключатель может быть **заблокирован** с подсказкой-popover:
- **Кампания** — если кампания закрыта (`closed`).
- **Группа** — если родительская кампания выключена.
- **Креатив** — если родительская группа или кампания выключена.

**Таблицы:** все.

---

## Moderation

Текстовый статус модерации: «Пройдена» или «В процессе». При незавершённой модерации текст выделен предупреждающим стилем.

**Таблицы:** кампании (все типы), группы (все типы). На креативах — нет.

---

## Budget

Два варианта отображения в зависимости от типа кампании:

**Прогресс-бар** (Brand Awareness, Performance, Preroll, Extension) — полоса «текущий / общий» бюджет в валюте рекламодателя. Дополнительно показывается **прогноз** — вертикальный маркер на полосе с popover-подсказкой при наведении. Прогноз рассчитывается на клиенте по датам кампании, текущим показам и среднему CPM.

**Число** (Special Project) — просто форматированная сумма бюджета без прогресс-бара и прогноза.

**Таблицы:** кампании (все типы), группы (BA, Performance, Preroll, Extension). У групп Special Project колонки нет.

---

## Views (Impressions)

Два варианта:

**Прогресс-бар** (BA, Performance, Preroll, Extension) — полоса «текущие / запланированные» показы. Без прогноза (в отличие от Budget).

**Число** (Special Project кампании) — форматированное число показов.

**Таблицы:** кампании (все типы), группы (BA, Performance, Preroll, Extension), креативы (BA, Extension). У групп и креативов Special Project — нет.

---

## CTR

Текстовое значение кликабельности: `row.ctr` с двумя знаками после запятой и символом `%`.

**Таблицы:** кампании (BA, Performance, Preroll, Extension), группы (те же), креативы (BA, Extension). Special Project — нет ни на одном уровне.

---

## Days Remaining

Целое число дней до окончания кампании / группы. Рассчитывается на клиенте: разница между датой окончания и текущим днём, минимум 0.

**Таблицы:** кампании (все типы), группы (BA, Performance, Preroll, Extension). У групп Special Project — нет. На креативах — нет.

---

## Advertiser

Название рекламодателя (`row.advertiser.title`). При длинном тексте — tooltip.

**Таблицы:** кампании (все типы, включая Special Project). На группах и креативах — нет.

---

## Channels

Число каналов, отформатированное с разделителями разрядов.

По умолчанию **скрыта** на уровне кампаний; на уровне групп — **видима** по умолчанию (кроме Special Project).

**Таблицы:** кампании (BA, Performance, Preroll, Extension), группы (BA, Performance, Preroll, Extension). Special Project — нет.

---

## Clicks

Число кликов, отформатированное с разделителями разрядов.

По умолчанию **скрыта** на всех уровнях.

**Таблицы:** кампании (BA, Performance, Preroll, Extension), группы (BA, Performance, Preroll, Extension). Special Project — нет.

---

## External ID

Идентификатор кампании во внешней системе. При длинном значении — tooltip.

**Таблицы:** только кампании **Performance**.

---

## Platform

Иконка и название стриминговой платформы (Twitch, YouTube, Trovo, VK Play, TikTok). Для групп — платформа самой группы; для креативов — платформа родительской группы.

**Таблицы:** группы (все типы), креативы (все типы). На кампаниях — нет.

---

## Format

Название формата размещения. Для групп — формат группы; для креативов — формат родительской группы.

**Таблицы:** группы (все типы), креативы (все типы). На кампаниях — нет.

---

## Related Campaign

Ссылка на родительскую кампанию (название кампании, клик ведёт на экран редактирования кампании).

**Таблицы:** группы (все типы), креативы (все типы). На кампаниях — нет.

---

## Related Group

Ссылка на родительскую группу (название группы, клик ведёт на экран редактирования группы).

**Таблицы:** креативы (все типы). На кампаниях и группах — нет.

---

## Bid Cap

Ставка в валюте рекламодателя.

**Таблицы:** только группы **Special Project**.

---

## Analytics

Иконка-ссылка на экран аналитики. Открывает раздел аналитики с предзаполненными параметрами: slug кампании, даты начала и окончания. Для групп и креативов URL содержит якорь `#creatives`.

**Таблицы:** кампании (BA, Performance, Preroll, Extension), группы (все типы), креативы (все типы). У кампаний Special Project — нет.
