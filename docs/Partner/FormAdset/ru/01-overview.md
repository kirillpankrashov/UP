# FormAdset — Обзор

## Что это

Экран в кабинете партнёра для **создания** или **редактирования группы (адсета)** внутри кампании. Группа — это уровень между кампанией и креативом: она определяет **бюджет**, **таргетинг**, **расписание** и **формат** размещения.

Подробнее про экран формы кампании — [FormCampaign — обзор](../../FormCampaign/ru/01-overview.md).

---

## Основные идеи

- Форма адсета зависит от **типа кампании** — набор полей, модель бюджета и таргетинг существенно различаются.
- **Создание** — открывается пустая форма; тип кампании берётся из URL (slug кампании).
- **Редактирование** — данные загружаются с сервера, тип кампании определяется из ответа API.
- **Дублирование** — из режима редактирования можно перейти к созданию нового адсета с предзаполненными данными текущего.

---

## Структура экрана

```
CampaignLayout (заголовок + боковая навигация структуры)
 ├── При загрузке: скелетон формы
 ├── При ошибке: сообщение + кнопка «Повторить»
 ├── Форма настроек (зависит от типа кампании)
 │    └── BrandAwareness | Performance | Preroll | Extension | SpecialProject
 └── Панель действий: «Назад», «Сохранить», «Дублировать» (в режиме редактирования)
```

---

## Типы кампаний и формы адсета

Каждый тип кампании имеет **свою секцию формы** с уникальным набором полей. Сводная таблица — в [формы по типам](./03-forms-by-campaign-type.md).

| Тип кампании | Модель бюджета | Особенности формы |
|---|---|---|
| Brand Awareness | PPV / CPC / CPA / PPVA (выбор стратегии) | Самая полная форма: время показа, частота, оповещения о конверсиях, расширенный таргетинг |
| Performance | Impressions / Actions (тип выплат) | Чатбот, креатив, пиксели аналитики, юридическая маркировка |
| Preroll | Impressions / Actions | Похож на Performance, но с видео-описанием вместо чатбота |
| Extension | PPV (стратегия из словаря) | Как Brand Awareness, но без времени показа, частоты и оповещений |
| Special Project | PPP (фиксированная стратегия) | Собственная таблица стримеров с ценами, настройки формата |

## Словари с бэкенда

### Словарь кампаний

Загружается при открытии экрана: `getCampaignDictionary(locale, campaignType)`. Из него используются:

| Поле / блок на экране | Поле в `dictStore` | Что даёт |
|---|---|---|
| Формат размещения | `campaigns.formats` | Список форматов (исключая `isExternalFormat`) |
| Платформа | `campaigns.platforms` | Список платформ (Twitch, YouTube и др.) |
| Стратегия оплаты (BA, Extension, SP) | `campaigns.strategyPaymentTypes` | PPV, CPC, CPA, PPVA, PPP |
| Частота показа (BA) | `campaigns.frequency`, `campaigns.frequencyPeriods` | Пресеты и периоды |
| Пол (таргетинг) | `campaigns.gender` | Мужской / женский / любой |
| Агентства (таргетинг) | `campaigns.agencies` | Список агентств с диапазонами CPM |

### Общий словарь кабинета

| Поле / блок на экране | Поле в `dictStore` | Что даёт |
|---|---|---|
| Языки (таргетинг) | `all.languages` | Список языков стримеров |
| Страны (таргетинг авторов) | `all.countries` | Список стран |
| Устройства (таргетинг аудитории) | `all.devices` | Список устройств |
| Теги (таргетинг) | `all.tags` | Список тегов контента |
| Часовой пояс | `all.timeZones` | Список часовых поясов |
| Категории кампаний | `all.campaignsCategories` | Определение dark market для поиска стримеров |

## Поток данных

Pinia-стор `useFormAdsetStore` управляет состоянием:

- **`adset`** — загруженные/обновлённые данные адсета (типизированное объединение по типам кампаний).
- **`currentCampaignType`** — тип текущей кампании; определяет, какая секция формы рендерится и какие API вызываются.
- **`audience`** — результат расчёта аудитории (показы, охват, количество стримеров).
- Флаги загрузки и ошибок.

При создании стор вызывает `createAdset`, при редактировании — `updateAdset`; конкретный API-эндпоинт выбирается по `currentCampaignType`. После успешного создания происходит редирект на экран редактирования созданного адсета и обновление структуры кампании.

**Кеширование:** ответы на чтение кешируются на клиенте; запросы создания и обновления сбрасывают связанный кеш.
