# FormAdset — Бюджетные модели

Модели бюджета определяют, **как рассчитывается стоимость размещения** и **за что платит рекламодатель**. Модель зависит от типа кампании; в некоторых типах пользователь выбирает стратегию из списка.

---

## Brand Awareness — стратегии оплаты

Выбор стратегии из выпадающего списка (`dictStore.campaigns.strategyPaymentTypes`). Доступны четыре варианта:

### PPV (Pay Per View)

Оплата за показы.

| Поле | Описание |
|---|---|
| `bidCap` (CPM) | Ставка за 1 000 показов |
| `impressions` | Количество показов |
| **Итого** | (impressions / 1 000) × bidCap |

### CPC (Cost Per Click)

Оплата за клики.

| Поле | Описание |
|---|---|
| `cpc` | Стоимость одного клика |
| `clicks` | Количество кликов |
| `cpcDailyLimit` | Дневной лимит расходов |
| **Итого** | cpc × clicks |

### CPA (Cost Per Action)

Оплата за конверсии.

| Поле | Описание |
|---|---|
| `cpa` | Стоимость одной конверсии |
| `conversions` | Количество конверсий |
| `cpaDailyLimit` | Дневной лимит расходов |
| **Итого** | cpa × conversions |

> При стратегии CPA на форме появляется секция **целей** — target EVR (ожидаемый коэффициент конверсий) и секция **оповещений** (анимация и текст для конверсионного алерта).

### PPVA (Pay Per View + Action)

Комбинированная модель: оплата за показы **и** за конверсии. Самая сложная стратегия.

| Поле | Описание |
|---|---|
| `bidCap` (CPM) | Ставка за 1 000 показов |
| `impressions` | Количество показов |
| `margin` (%) | Маржа |
| `agencyCommission` (%) | Комиссия агентства |
| `cpmPercent` (%) | Доля CPM в разбивке |
| `cpa` | Стоимость конверсии |
| **Итого** | (impressions / 1 000) × bidCap |

Итоговый бюджет рассчитывается так же, как в PPV. Далее форма показывает **разбивку**:

- **Маржа** = итого × margin%
- **Комиссия агентства** = итого × agencyCommission%
- **Остаток** = итого − маржа − комиссия → делится по `cpmPercent` на CPM-часть и CPA-часть для авторов
- **Конверсии** = итого / cpa (округлённо)
- **CPM авторов** и **CPA авторов** — расчётные ставки из разбивки

При PPVA также появляется секция **целей** (target CTR) и секция **оповещений**.

## Performance и Preroll — тип выплат

Вместо стратегии используется **тип выплат** (`PayoutType`):

### Impressions (за показы)

| Поле | Описание |
|---|---|
| `bidCap` | Ставка за 1 000 показов |
| `impressions` | Количество показов |
| **Итого** | (impressions / 1 000) × bidCap (в валюте) |

### Actions (за действия)

| Поле | Описание |
|---|---|
| `bidCpa` | Стоимость одного действия |
| `budget` | Общий бюджет |
| **Итого** | floor(budget / bidCpa) — количество действий |

> В секции целей Performance и Preroll показываются поля **target CTR** и **target CPA**.

---

## Extension — PPV

Extension использует выбор стратегии из словаря (как Brand Awareness), но в текущей реализации **только PPV** рендерит UI-компонент. Другие стратегии из словаря не имеют соответствующих секций бюджета.

| Поле | Описание |
|---|---|
| `bidCap` (CPM) | Ставка за 1 000 показов |
| `impressions` | Количество показов |
| **Итого** | (impressions / 1 000) × bidCap |

---

## Special Project — PPP (Pay Per Placement)

Фиксированная стратегия, выбор не предоставляется.

| Поле | Описание |
|---|---|
| `bidCap` | Ставка (отображается как CPM в UI) |

> Итоговая стоимость размещения не рассчитывается на форме. Стоимость для каждого стримера задаётся отдельно в **таблице стримеров** — у каждого стримера своя цена в валюте рекламодателя.

---

## Связь стратегии с другими секциями формы

| Стратегия | Цели | Оповещения | Частота |
|---|---|---|---|
| PPV (BA) | target CTR | − | + |
| CPC (BA) | − | − | + |
| CPA (BA) | target EVR | + (анимация, текст) | + |
| PPVA (BA) | target CTR | + (анимация, текст) | + |
| Impressions (Perf/Preroll) | target CTR + CPA | − | − |
| Actions (Perf/Preroll) | target CTR + CPA | − | − |
| PPV (Extension) | target CTR | − | − |
| PPP (Special Project) | − | − | − |
