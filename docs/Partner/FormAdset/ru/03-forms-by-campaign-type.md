# FormAdset — Форма по типам кампаний

**Все поля и секции** на экране настроек адсета по типам кампаний. **+** — элемент есть, **−** — нет. Подробные описания полей — в [справочнике полей](./05-field-reference.md), модели бюджета — в [бюджетных моделях](./04-budget-models.md).

**Откуда значения в списках:** форматы, платформы, стратегии оплаты, частота, пол — из **словаря кампаний**; языки, страны, устройства, теги, часовые пояса — из **общего словаря** кабинета. Сводка — в [обзоре](./01-overview.md).

---

## Общие настройки

| Поле или секция | Brand Awareness | Performance | Preroll | Extension | Special Project |
|---|---|---|---|---|---|
| Статус (вкл./выкл.) | + | + | + | + | + |
| Название | + | + | + | + | + |
| Описание | + | + | + | + | + |
| Платформа | + | + | + | + | + |
| Формат | + | + | + | + | + |
| Настройки формата | − | − | − | − | + |
| Расписание (даты) | + | + | + | + | + |
| Часовой пояс | + | + (заблокирован) | − | − | + |
| Время показа (daypart) | + | − | − | − | − |

> **Статус** — только в режиме **редактирования**; при создании блок не показывается.
>
> **Часовой пояс** у Performance отображается, но **заблокирован** (значение нельзя менять). У Preroll и Extension блок часового пояса **не показывается**.
