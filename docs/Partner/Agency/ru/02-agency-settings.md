# Agency — Настройки выплат

Настройки выплат агентства задают правила начисления стримерам за показы рекламы. Доступны только для обычных агентств (не Uplify). Редактирование — только для пользователей с ролью Admin.

---

## Расположение

Вкладка **Overview** → секция «Creators payout» (компонент `AgencySettings`).

---

## Структура настроек

### Участие сторонних партнёров

Чекбокс `streamersParticipate` — разрешает сторонним партнёрам размещать рекламу у стримеров агентства. Когда включён, появляются поля для внешних ставок.

### Комиссия

Поле `commission` — процент комиссии агентства. Используется для кампаний с индивидуальными договорённостями или когда ставки стримерам не настроены.

### Ставки CPM/CPA/CPC

Ставки задаются по рекламным форматам. Редактируемые форматы:

| Формат | Описание |
|---|---|
| Fullscreen (Overlay 50%) | Полноэкранный оверлей |
| PiP (Overlay 15%) | Picture-in-Picture |
| Custom | Произвольный формат |
| Interactive | Интерактивный формат |
| Preroll | Pre-Roll видео |

Для каждого формата задаются до четырёх групп ставок:

| Группа | Поле в `TCPM` | Когда доступна |
|---|---|---|
| Внутренние ставки | `internalCpm` | Всегда |
| Внешние ставки | `externalCpm` | Когда `streamersParticipate = true` |
| Dark market внутренние | `darkMarketInternalCpm` | Когда `useDarkMarket = true` |
| Dark market внешние | `darkMarketExternalCpm` | Когда оба флага включены |

### Placeholder'ы в полях ставок

Компонент `CostInputs`, который рендерит поля CPM/CPA/CPC, подставляет базовые ставки из словаря кампаний в качестве placeholder'ов:

| Тип | Источник |
|---|---|
| CPM (по форматам) | `dictStore.campaigns.agenciesPayableCpm[format]` |
| CPA | `dictStore.campaigns.agenciesPayableCpa` |
| CPC | `dictStore.campaigns.agenciesPayableCpc` |

Эти значения показываются как подсказки в пустых полях — чтобы администратор видел текущие базовые ставки при настройке индивидуальных.

### Dark market

Чекбокс `useDarkMarket` — включает повышенные ставки для категорий «тёмного рынка» (gambling, casino, crypto и т.д.). При включении появляются дополнительные поля для dark-market ставок.

### Стоп-лист категорий

Секция «Categories stop list» (`ignoredCategories`) — выбор категорий кампаний, которые будут автоматически скрыты от стримеров агентства в разделе In-stream ads. Категории берутся из глобального словаря `dictStore.all.campaignsCategories`.

---

## Сохранение

Форма отправляется через `agencyStore.updateData()` → `POST partner/agency/save`. Payload включает все поля агентства: `commission`, `streamersParticipate`, `useDarkMarket`, `cpm`, `ignoredCategories`.

> После сохранения `fetchData()` не перезагружает данные с сервера (short-circuit по `if (this.data) return`). Обновление в UI происходит из-за реактивности формы, но серверные нормализации не отразятся до полной перезагрузки страницы.

---

## Переопределение ставок для стримера

Помимо агентских ставок, для каждого стримера можно задать индивидуальные ставки. Это делается в сайдбаре «Settings» на вкладке **Creators** (подробнее — в документе [03-streamers](03-streamers.md)).

Структура переопределения повторяет агентские ставки (`TCPM`), но применяется к конкретному стримеру через `POST partner/agency/streamer/:id/save`.
