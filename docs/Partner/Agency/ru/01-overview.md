# Agency — Обзор

Раздел **Agency** (в интерфейсе — «Creators») — это панель управления агентством в партнёрском кабинете. Здесь партнёр управляет подключёнными стримерами, настраивает ставки выплат, просматривает рекламные кампании и ведёт биллинг.

---

## Ключевые понятия

| Понятие | Описание |
|---|---|
| **Агентство** | Организация-партнёр, к которой привязаны стримеры. Каждое агентство имеет свой `id`, настройки ставок и кошелёк |
| **Uplify-агентство** | Специальное агентство с `id === 1`. Видит урезанный интерфейс: только обзор с реферальной программой и историю транзакций |
| **Стример (Creator)** | Контент-мейкер, привязанный к агентству. Агентство управляет его ставками и видит его статистику |
| **Реферальная ссылка** | Ссылка для привлечения новых стримеров. Доступна всем агентствам |
| **Dark market** | Повышенные ставки для категорий вроде gambling, casino, crypto |
| **CPM / CPA / CPC** | Модели оплаты: за тысячу показов / за действие / за клик |

## Вкладки

Набор вкладок зависит от типа агентства:

| Вкладка | URL `?tab=` | Обычное агентство | Uplify-агентство |
|---|---|---|---|
| Overview | `overview` | Да | Да |
| Transaction history | `history` | — | Да |
| Creators | `streamers` | Да | — |
| Campaigns | `adsets-active` | Да | — |
| Closed | `adsets-closed` | Да | — |
| Billing | `billing` | Да | — |

Активная вкладка синхронизируется с query-параметром `?tab=` в URL. По умолчанию открывается `overview`.

## Инициализация

При монтировании `Agency.vue`:

1. Загружается словарь кампаний через `dictStore.getCampaignDictionary(locale, BRAND_AWARENESS)`. Словарь содержит данные, которые используются дочерними компонентами:
   - `campaignsCategories` — список категорий кампаний (для стоп-листа в настройках агентства)
   - `agenciesPayableCpm` / `agenciesPayableCpa` / `agenciesPayableCpc` — базовые ставки по форматам (используются как placeholder'ы в полях ввода ставок)
   - `currencies` — справочник валют (для отображения иконки валюты в формах)
2. Вызывается `agencyStore.fetchData()`, который:
   - Загружает данные агентства (`GET partner/agency`)
   - Загружает реферальные данные (`GET partner/referral`)
   - Если это Uplify-агентство — дополнительно загружает список реферальных стримеров

> Данные агентства загружаются один раз и кэшируются в сторе. Повторный вызов `fetchData()` возвращается сразу, если `data` уже заполнена.

## Роли и доступ

Раздел доступен партнёрам с привязанным агентством. Внутри раздела уровень доступа определяется полем `roleExtended` из профиля партнёра:

- **Admin** — полный доступ к редактированию ставок (агентских и per-streamer)
- **Остальные роли** — просмотр данных, формы заблокированы
