# Agency — Реферальная программа

Реферальная программа позволяет агентству привлекать новых стримеров через уникальную ссылку и получать долю от их дохода. Базовая реферальная функциональность (ссылка + баланс) доступна всем агентствам, расширенная (список стримеров + история) — только Uplify-агентству.

---

## Реферальная ссылка

Отображается в секции «Invitation link» на вкладке **Overview**, если у агентства есть реферал (`referralStore.referral?.link`).

Компонент `ReferralLink` показывает ссылку с кнопкой копирования (через `useClipboard`). Стример, зарегистрировавшийся по этой ссылке, автоматически привязывается к агентству.

> В кодовой базе нет эндпоинта «attach referral». Привязка происходит на стороне бэкенда при регистрации по ссылке. Эндпоинт `detachReferral` реализован (`POST partner/referral/detach`), но не подключён к UI.

---

## Баланс и статистика

Компонент `Balance` на вкладке **Overview** отображает сводку. Источник данных зависит от типа агентства:

| Метрика | Обычное агентство | Uplify-агентство |
|---|---|---|
| Приглашённые | Из данных агентства | `referral.invited` |
| Сумма к выплате | Из кошелька агентства | `referral.balance` |
| Валюта | Из кошелька агентства | `referral.currency` |

---

## Список реферальных стримеров (только Uplify)

Для Uplify-агентства (`id === 1`) на вкладке **Overview** отображается drawer `StreamersList` со списком привлечённых стримеров.

Данные загружаются через `GET partner/referral/creators` при инициализации модуля. Список содержит имена стримеров и суммы их заработков.

Ссылка «Creators list» на Overview открывает этот drawer (для обычных агентств — переключает на вкладку Creators).

---

## История транзакций (только Uplify)

Вкладка **Transaction history** (`Tab.HISTORY`) доступна только Uplify-агентству.

### Таблица истории

Загружается через `GET partner/referral/history` с пагинацией. Показывает:

| Колонка | Описание |
|---|---|
| Date | Дата транзакции |
| Payment per day | Сумма выплат за день |
| Details | Кнопка детализации |

Заголовок секции отображает общую сумму за всё время (`history.amount`).

### Детализация

При клике на строку открывается drawer с детализацией за конкретный день. Загружается через `GET partner/referral/history/detail?date=YYYY-MM-DD`.

Показывает список стримеров, которые принесли доход в этот день, с суммами.

---

## Загрузка данных

Реферальные данные загружаются каскадно при инициализации Agency:

```
agencyStore.fetchData()
 └── referralStore.fetchReferral()           — GET partner/referral
      └── referralStore.fetchReferralStreamers()  — GET partner/referral/creators (только id === 1)
```

Все три запроса имеют short-circuit: если данные уже есть, повторный вызов не делает запрос.
