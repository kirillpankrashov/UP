# Agency — Управление стримерами

Вкладка **Creators** содержит список стримеров, привязанных к агентству. Доступна только для обычных агентств (не Uplify).

---

## Список стримеров

Таблица с пагинацией «Load more» и поиском с debounce.


| Колонка       | Описание                  |
| ------------- | ------------------------- |
| Creator       | Имя стримера              |
| Last activity | Дата последней активности |
| Balance       | Баланс кошелька стримера  |
| Campaign      | Количество кампаний       |


Поиск (`Search`) вызывает `fetchStreamers(1, false, query)` с задержкой, сбрасывая пагинацию. Кнопка «Load more» вызывает `fetchStreamers(page + 1, true)`, дозагружая следующую страницу.

---

## Статусы стримера

У каждого стримера три статусных флага, отображаемых иконками с popover-подсказками:


| Флаг              | Условие | Значение                       |
| ----------------- | ------- | ------------------------------ |
| `checkListStatus` | `false` | Стример не завершил onboarding |
| `payableStatus`   | `false` | Не настроены выплаты           |
| `ctrStatus`       | `false` | Низкий CTR по кампаниям        |


Статусы только для отображения — никакого API вызова при клике.

## Сайдбар «Settings»

Открывается кликом по стримеру → иконка настроек. Загружает данные через `GET partner/agency/streamer/:id/info`.

Содержит форму для индивидуальных ставок стримера:

- **Custom payout** — ставки CPM/CPA/CPC по форматам, аналогично агентским настройкам
- **Dark market rates** — если на уровне агентства включён `useDarkMarket`

### Иконка валюты

Знак валюты в полях ввода ставок определяется через словарь `dictStore.all.currencies`. Компонент ищет валюту по `id`, совпадающему с `agencyStore.data.wallet.currency`, и берёт из неё поле `icon`. Если валюта не найдена — подставляется `$` (USD) по умолчанию.

### Placeholder'ы ставок

Поля ставок рендерятся компонентом `CostInputs`. Если для стримера задана индивидуальная ставка — она показывается как placeholder. Если нет — подставляется базовая ставка из словаря кампаний (`dictStore.campaigns.agenciesPayableCpm/Cpa/Cpc`). Подробнее о механизме placeholder'ов — в [02-agency-settings](02-agency-settings.md).

### Доступность полей

Доступность полей зависит от:

- `agencyStore.data.streamersParticipate` — показываются ли внешние ставки
- `agencyStore.data.useDarkMarket` — показываются ли dark-market ставки
- Роль пользователя (`isAdmin`) — можно ли редактировать

Сохранение: `POST partner/agency/streamer/:id/save` через `streamersStore.updateStreamerInfo()`.

## Сайдбар «Campaigns»

Открывается кликом по стримеру → иконка кампаний. Загружает данные через `GET partner/agency/streamer/:id/report`.

Показывает таблицу кампаний стримера с колонками: название кампании, доход, просмотры, CTR, статус.

---

## Кэширование и данные

- Список стримеров не кэшируется между загрузками — каждый запрос идёт на сервер
- Инфо стримера кэшируется по `streamerId` — повторное открытие того же стримера не делает запрос
- При открытии другого стримера предыдущие данные заменяются
