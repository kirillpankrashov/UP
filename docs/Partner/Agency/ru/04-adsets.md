# Agency — Рекламные кампании

Вкладки **Campaigns** и **Closed** показывают рекламные наборы (ad sets), доступные стримерам агентства. Видны только обычным агентствам (не Uplify).

---

## Активные и закрытые кампании

Два таба с идентичной механикой, но разными данными:


| Вкладка              | API                                       | Store                          |
| -------------------- | ----------------------------------------- | ------------------------------ |
| Campaigns (активные) | `GET partner/agency/:campaignType/active` | `partner-agency-adsets-active` |
| Closed (закрытые)    | `GET partner/agency/:campaignType/closed` | `partner-agency-adsets-closed` |


По умолчанию `campaignType = BRAND_AWARENESS`. Переключение типа кампании доступно через UI (компонент `AdsetsList`).

---

## Список рекламных наборов

Компонент `AdsetsList` отображает карточки ad sets с пагинацией. Каждая карточка (`AdsetCard`) содержит:

- Название кампании и ad set
- Теги (формат, лимиты, статус расширения)
- Индикаторы (просмотры, доход, CTR)
- Кнопки: открыть инфо, открыть отчёт по стримерам

---

## Сайдбар «Campaign Info»

Открывается при клике на карточку. Загружает данные через `GET partner/agency/:campaignType/:slug/info`.

Отображает:


| Поле         | Описание                 |
| ------------ | ------------------------ |
| Даты         | Начало и конец кампании  |
| Bid cap      | Максимальная ставка      |
| Frequency    | Частота показа           |
| Format       | Рекламный формат         |
| Payment type | Тип оплаты (CPM/CPA/CPC) |
| Category     | Категория рекламодателя  |
| Description  | Описание кампании        |


Секция **Creative preview** показывает креативы из массива `ads`. Отображение зависит от типа кампании:

- **Brand Awareness** — вложения (изображения, видео), текст чат-бота, ссылка на продукт
- **Performance** — аналогично, но с акцентом на действия (CPA)

---

## Сайдбар «Campaign Report»

Открывается кнопкой «Report» на карточке. Загружает `GET partner/agency/:campaignType/:slug/report`.

Таблица стримеров, участвующих в ad set:


| Колонка | Описание           |
| ------- | ------------------ |
| Creator | Имя стримера       |
| Income  | Доход              |
| Views   | Просмотры          |
| CTR     | Click-through rate |
| Status  | Статус участия     |


---

## Определение типа кампании по slug

При открытии ad set тип кампании определяется из slug через утилиту `parseSlug()`. Это позволяет корректно маршрутизировать API-запросы, даже если пользователь переключился между типами.

---

## Данные

- Ad set info кэшируется по `slug` — повторное открытие того же набора не вызывает запрос
- При переключении типа кампании список перезагружается с первой страницы
- Списки стримеров по ad set пагинируются отдельно
