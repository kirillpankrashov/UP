# FormCampaign — Форма по типам кампаний

Ниже — **все поля и секции** на экране настроек кампании по типам. В ячейках: **+** — элемент есть на форме этого типа, **−** — нет. Подписи как в интерфейсе (русская локализация). Текстовые описания полей — в [справочнике полей](./04-field-reference.md).

**Откуда значения в списках:** **категория** и **часовой пояс** (если поле есть) — из **общего словаря** кабинета; **холдинг**, **медиа агентство**, варианты в **партнёрских сетях** — из **словаря кампаний**; **рекламодатель** — из **отдельного запроса** по холдингу. Сводка — в [обзоре](./01-overview.md).

---

## Поля и секции по типам кампании

| Поле или секция | Brand Awareness | Performance | Preroll | Extension | Special Project |
|---|---|---|---|---|---|
| Статус (видимость) | + | + | + | + | + |
| Название | + | + | + | + | + |
| Описание кампании | + | + | + | + | + |
| Внешний ID | − | + | − | − | − |
| Категория | + | + | + | + | + |
| Дата начала / дата окончания | + | + | + | + | + |
| Часовой пояс | + | + | − | − | + |
| Холдинг рекламодателя | + | + | + | + | + |
| Рекламодатель | + | + | + | + | + |
| Медиа агентство | + | + | + | + | + |
| ОРД маркировка | + | + | + | + | + |
| Партнёрские сети | + | − | − | − | + |
| Конструктор GET параметров | + | + | + | + | + |
| Uplify Pixel | + | + | + | + | + |

> **Статус** — строка в таблице относится к режиму **редактирования**; при **создании** кампании этого блока нет ни у одного типа. Это переключатель **кампании**; фактическая видимость размещения у автора зависит ещё от адсета, креатива и таргетинга — см. [справочник полей](./04-field-reference.md).
>
> **Часовой пояс** у **Performance** на экране **есть** (`+`), но поле **заблокировано**: значение менять нельзя. У **Preroll** и **Extension** блок часового пояса на этой форме **не показывается** (`−`).
