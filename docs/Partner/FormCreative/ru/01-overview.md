# FormCreative — Обзор

## Что это

Экран в кабинете партнёра для **создания** или **редактирования креатива** внутри адсета. Креатив — самый нижний уровень в иерархии «кампания → адсет → креатив»: он определяет **контент размещения** — загруженные файлы, ссылки, тексты чатбота, пиксели аналитики.

Подробнее про экран формы адсета — [FormAdset — обзор](../../FormAdset/ru/01-overview.md).

---

## Основные идеи

- Форма креатива зависит от **типа кампании** — набор полей, типы загружаемых файлов и дополнительные секции различаются.
- **Поддерживаемые типы**: Brand Awareness, Extension, Special Project. У Performance и Preroll форма креатива **отсутствует** — контент для этих типов задаётся на уровне адсета.
- **Создание** — открывается пустая форма; тип кампании берётся из slug кампании в URL.
- **Редактирование** — данные загружаются с сервера (`fetchCreative`), тип определяется из ответа API.
- Кнопка **«Дублировать»** отсутствует — в отличие от FormAdset, на форме креатива есть только «Назад» и «Сохранить».

---

## Структура экрана

```
CampaignLayout (заголовок + боковая навигация структуры кампании)
 ├── При загрузке: скелетон формы
 ├── При ошибке: сообщение + кнопка «Повторить»
 ├── Форма настроек (зависит от типа кампании)
 │    └── BrandAwareness | Extension | SpecialProject
 └── Панель действий: «Назад», «Сохранить»
```

---

## Типы кампаний и формы креатива

| Тип кампании | Основной контент | Особенности формы |
|---|---|---|
| Brand Awareness | Видео / ZIP (зависит от формата адсета) | Полная форма: файл, ссылки на продукт, чатбот, QR-код, Ad Tag (ADMNG), пиксели, ERID |
| Extension | Баннер / Квиз / Галерея (зависит от формата) | Специализированные редакторы для каждого формата, превью-файл, без чатбота |
| Special Project | Видео / ZIP (зависит от формата адсета) | Как Brand Awareness, но требования к файлам берутся из словаря (`formatRequirements`) |

### Где показываются креативы

- **Brand Awareness** — креативы отображаются в основном **виджете** (`src/modules/Widget`), который встраивается в OBS стримера.
- **Special Project** — креативы отображаются в специальном **виджете Special Project** (`src/modules/SpecialProjectWidget`), который также встраивается в OBS стримера.
- **Extension** — креативы отображаются в **Twitch-расширении** (Extension). Код и документация расширения находятся в отдельном репозитории.

## Словари с бэкенда

Форма креатива использует **словарь кампаний** (`getCampaignDictionary`), загружаемый при открытии экрана.

| Поле / блок на экране | Поле в `dictStore` | Что даёт |
|---|---|---|
| Требования к файлам (SP) | `campaigns.formatRequirements` | Текстовые описания требований к файлу для формата адсета |

> Большинство данных формы креатива не зависят от словарей — это пользовательский ввод (тексты, URL, файлы). Словарь критичен для Special Project, где описания требований к файлам формируются динамически.

## Поток данных

Pinia-стор `useFormCreativeStore` управляет состоянием:

- **`creative`** — загруженные/созданные данные креатива (типизированное объединение: `IBrandAwarenessCreative | IExtensionCreative | ISpecialProjectCreative`).
- **`currentCampaignType`** — тип текущей кампании; определяет, какая секция формы рендерится и какие API вызываются.
- Флаги `isFetchingCreative` и `fetchError`.

При создании стор вызывает `createCreative(model)`, при редактировании — `updateCreative(model)` (который после успешного обновления перезагружает данные через `fetchCreative`). Конкретный API-эндпоинт выбирается по `currentCampaignType`.

После успешного создания происходит редирект на экран редактирования созданного креатива и обновление структуры кампании.

**Кеширование:** ответы на чтение кешируются на клиенте (TTL 1 час); запросы создания и обновления сбрасывают связанный кеш.
