# FormCreative — Форма по типам кампаний

**Все поля и секции** на экране настроек креатива по типам кампаний. **+** — элемент есть, **−** — нет. Подробные описания полей — в [справочнике полей](./05-field-reference.md), загрузка файлов — в [загрузке файлов](./04-file-uploads.md).

> У Performance и Preroll форма креатива **отсутствует** — контент для этих типов задаётся на уровне адсета.

---

## Общие настройки

| Поле или секция | Brand Awareness | Extension | Special Project |
|---|---|---|---|
| Статус (вкл./выкл.) | + | + | + |
| Название | + | + | + |
| Альтернативное название | + | + | + |

> **Статус** — только в режиме **редактирования**; при создании блок не показывается.
>
> **Альтернативное название** — опциональное, добавляется по кнопке «Добавить альтернативное название».

## Файлы и медиа

| Поле или секция | Brand Awareness | Extension | Special Project |
|---|---|---|---|
| Загрузка креатива (видео / ZIP) | + (Overlay 50%, Overlay 15%, Custom) | − | + |
| Баннер (banner + unit, изображения/видео) | − | + (EXT_BANNER) | − |
| Квиз (интерактивный, изображения/видео) | − | + (EXT_QUIZ) | − |
| Галерея (слайды: изображения/видео) | − | + (EXT_GALLERY) | − |
| CSS-редактор стилей | − | + (все форматы) | − |
| Превью-файл | − | + | − |
| Предпросмотр креатива | + (если файл загружен) | + (баннер / галерея / квиз) | − |

> **Brand Awareness**: секция файлов появляется только для форматов **Overlay 50%** (FULLSCREEN), **Overlay 15%** (PIP) или **Custom** (CUSTOM). Для форматов спонсорских сообщений (Chatbot / Text) загрузка файла отсутствует — контент состоит из текста и ссылок. Для ADMNG вместо файла используется **Google Ad Tag**.
>
> **Extension**: тип контента определяется форматом адсета — **EXT_BANNER** (баннер + unit-файл), **EXT_QUIZ** (интерактивный квиз), **EXT_GALLERY** (галерея слайдов). Все три формата принимают как изображения, так и видео (PNG, JPG, GIF, MP4, WEBM). Для каждого формата доступен **полноэкранный CSS-редактор**, позволяющий полностью переопределить внешний вид креатива.
