# FormCreative — Загрузка файлов

Типы и ограничения загружаемых файлов зависят от **типа кампании** и **формата адсета**. Файлы загружаются через GCS (`gcp/upload/config`), после чего для Brand Awareness и Extension вызывается `verifyAttachment` для валидации на сервере.

---

## Brand Awareness

Секция загрузки файлов отображается только для форматов **Overlay 50%**, **Overlay 15%** и **Custom**. Для остальных форматов секция не показывается.

| Формат адсета | Альт. название | Поле | Тип файла | Макс. размер |
|---|---|---|---|---|
| FULLSCREEN | Overlay 50% | `video` | Видео | 15 МБ |
| PIP | Overlay 15% | `video` | Видео | 15 МБ |
| CUSTOM | Custom | `zip` | ZIP-архив | 10 МБ |

### Форматы без загрузки файла

| Формат | Что вместо файла |
|---|---|
| ADMNG | Секция **Google Ad Tag** — текстовое поле для скрипта |
| LEADERBOARD | Нет секции файлов |
| Спонсорское сообщение (Chatbot / Text) | Нет загрузки файла — креатив состоит только из текста чатбота, ссылок и пикселей |

> Для форматов спонсорских сообщений основной контент — это **текст чатбота** и **ссылка на продукт**. Секция загрузки медиафайла отсутствует.

- После загрузки вызывается `verifyAttachment` с `format: BRAND_AWARENESS` и ключом файла.
- При удалении в режиме редактирования вызывается `deleteAttachment`.
- Если файл загружен, доступен предпросмотр в диалоговом окне.
- Требования к файлу отображаются из локалей: `creative.form.files.requirements.fullscreen`, `pip_video`, `custom` с подстановкой размера.

## Extension

Тип медиа-контента определяется форматом адсета. Все три формата Extension принимают как изображения, так и видео: **PNG, JPG, GIF, MP4, WEBM**.

Для каждого формата доступен **полноэкранный CSS-редактор** — CodeMirror с подсветкой синтаксиса CSS. CSS-стили сохраняются в поле `styles` модели и позволяют **полностью переопределить внешний вид** креатива: цвета, шрифты, размеры, позиционирование, анимации. Стили инжектируются в превью как `<style>` блок.

### EXT_BANNER (баннер)

Два файла: **banner1** (панель 728×90) и **banner2** / unit (оверлей 550×310).

| Файл | Макс. размер | Допустимые типы | Описание |
|---|---|---|---|
| `banner1` | 5 МБ | PNG, JPG, GIF, MP4, WEBM | Основной баннер (панель) |
| `banner2` (unit) | 10 МБ | PNG, JPG, GIF, MP4, WEBM | Unit-файл (раскрытый вид) |

Оба файла могут быть **изображениями или видео** — компонент `ImageOrVideo` автоматически определяет тип при рендере. Превью показывает `banner1` как горизонтальную панель; при взаимодействии раскрывается `banner2`.

**CSS-редактор** (`EditorBanner`): редактирует `model.panel.styles`. Левая часть — CodeMirror, правая — живой предпросмотр баннера с применёнными стилями.

### EXT_QUIZ (квиз)

Интерактивный квиз с настройками: экран приветствия, вопросы (2–4 варианта ответа), результаты. Фоновые изображения для экранов загружаются отдельно.

| Файл | Макс. размер | Допустимые типы |
|---|---|---|
| Фон экрана квиза | 5 МБ | PNG, JPG, GIF, MP4, WEBM |

Настройки квиза (`FormQuiz`): включение/выключение квиза, показ правильных ответов, пагинация, показ результатов, тексты, цвета, CTA-кнопка.

**CSS-редактор** (`EditorQuiz`): редактирует `model.quiz.styles`. При создании стили инициализируются шаблоном `generateDefaultStyles()` с заготовками для `.wrapper`, `.welcome-screen`, `.question-screen`, `.result-screen` и др. Все CSS-селекторы должны быть с префиксом `._campaign`.

Живой предпросмотр (`QuizInstance`) обновляется в реальном времени при изменении стилей и контента.

### EXT_GALLERY (галерея)

Набор слайдов. Каждый слайд может быть **изображением или видео**.

| Файл | Макс. размер | Допустимые типы |
|---|---|---|
| Слайд галереи | 5 МБ | PNG, JPG, GIF, MP4, WEBM |

Количество слайдов **не ограничено** на уровне клиента. Для видео-слайдов карусель учитывает длительность видео при автоматической прокрутке.

**CSS-редактор** (`EditorGallery`): редактирует `model.gallery.styles`. Карусель в превью имеет фиксированные размеры (236×350), стили позволяют кастомизировать элементы внутри.

### Превью-файл (все форматы Extension)

Общий для всех форматов Extension — загрузка видеофайла превью.

| Файл | Допустимые типы | Макс. размер |
|---|---|---|
| `preview` | MP4, WEBM | 2 МБ |

> Превью-файл — **обязательное** поле для Extension.

## Special Project

| Формат адсета | Поле | Тип файла | Макс. размер |
|---|---|---|---|
| SP_CUSTOM | `zip` | ZIP-архив | 10 МБ |
| Остальные (SP_FULLSCREEN и др.) | `video` | Видео | 50 МБ |

- Требования к файлу берутся из **словаря** — `dictStore.campaigns.formatRequirements`, а не из статичных локалей.
- `verifyAttachment` **не вызывается** для Special Project.
- При удалении в режиме редактирования вызывается `deleteAttachment`.

---

## Общий механизм загрузки

1. Пользователь выбирает или перетаскивает файл.
2. Клиент получает подписанный URL через `gcp/upload/config`.
3. Файл загружается напрямую в GCS.
4. Ключ файла сохраняется в модели формы.
5. Для BA и Extension: `verifyAttachment` валидирует файл на сервере.
6. При обновлении креатива файл отправляется на сервер **только если путь содержит `tmp/`** (новая загрузка); существующие файлы не перезагружаются.
