# FormCreative — Создание и редактирование

Поведение экрана с точки зрения пользователя: шаги, кнопки, валидация, сохранение и выход.

---

## Создание креатива

1. Пользователь переходит к созданию креатива из экрана адсета. **Тип кампании** определяется из slug кампании в URL.
2. Параллельно загружаются: **словарь кампаний** для нужного типа, **список рекламодателей**, **структура кампании** (для боковой навигации), **данные адсета** (для определения формата).
3. Пока идёт загрузка, отображается скелетон формы.
4. После загрузки открывается пустая форма настроек креатива (конкретная секция зависит от типа кампании).
5. Основное действие — **«Сохранить»**. После успешного сохранения пользователь **не возвращается в список** — происходит редирект на экран **редактирования** только что созданного креатива.

---

## Редактирование креатива

1. При открытии загружаются данные креатива (`fetchCreative`) вместе со словарём кампаний и данными адсета. Тип кампании определяется из ответа API.
2. Если загрузка **не удалась** (креатив, адсет или структура кампании) — отображается сообщение об ошибке с кнопкой **«Повторить»**. Повторная попытка сбрасывает флаги ошибок и запускает загрузку заново.
3. В верхней части формы может быть **переключатель статуса** (вкл./выкл.). Изменение статуса вызывает `changeStatus` на уровне кампании (тип сущности — `CREATIVES`), затем обновляет креатив.

---

## Сохранение и валидация

- Во время выполнения запроса форма **блокируется** (кнопка «Сохранить» показывает индикатор загрузки) для предотвращения повторной отправки.
- Если **обязательные поля** не заполнены, сохранение не проходит: проблемные поля подсвечиваются.
- После успешного сохранения показывается подтверждение (3 секунды), затем при создании — редирект на экран редактирования.

### Обязательные поля по типам

| Тип кампании | Обязательные поля |
|---|---|
| Brand Awareness | Название, ссылка на продукт (основная), текст чатбота |
| Extension | Название, ссылка на продукт (основная), превью-файл |
| Special Project | Название, ссылка на продукт (основная), текст чатбота |

> Пиксели аналитики (click pixels) валидируются как URL, если заполнены. Мобильная ссылка на продукт валидируется как URL, но не обязательна.

---

## Несохранённые изменения

Если пользователь изменил данные по сравнению с пустым черновиком (создание) или последней сохранённой версией (редактирование), при попытке уйти с экрана появляется диалог подтверждения через `CampaignLayout.showCloseDialog`.

---

## Куда ведёт «Назад» / закрытие

Маршрут возврата зависит от типа кампании и режима:

| Режим | Маршрут |
|---|---|
| Создание (Brand Awareness) | Список креативов Brand Awareness |
| Создание (Extension) | Список креативов Extension |
| Создание (Special Project) | Список креативов Special Project |
| Редактирование | Определяется типом: `BRAND_AWARENESS_CREATIVES`, `EXTENSION_CREATIVES` или `SPECIAL_PROJECT_CREATIVES` |
