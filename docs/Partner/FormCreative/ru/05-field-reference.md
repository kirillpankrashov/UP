# FormCreative — Справочник полей

Подробное описание элементов формы креатива. Сводные таблицы «есть / нет» по типам — в [формах по типам](./03-forms-by-campaign-type.md). Загрузка файлов — в [загрузке файлов](./04-file-uploads.md).

---

## Статус (видимость)

Переключатель **вкл./выкл.** креатива. Изменение статуса вызывает `changeStatus` на уровне кампании с типом сущности `CREATIVES`, затем обновляет креатив.

Чтобы автор **увидел размещение**, одновременно должны быть включены: **кампания**, **адсет**, **креатив** (и креатив должен быть валиден). Если выключен креатив — автор не увидит размещение.

> Компонент использует локали из **FormAdset**, а не FormCreative.

**Формы:** все типы — **только редактирование**.

---

## Название

Рабочее название креатива. Текстовое поле, обязательное, максимум 120 символов.

**Формы:** все типы.

---

## Альтернативное название

Дополнительное название креатива. По умолчанию скрыто — появляется по нажатию кнопки «Добавить альтернативное название». Максимум 120 символов.

Доступно только если модель данных креатива содержит поле `title.alternative` (Brand Awareness, Extension, Special Project — все три типа).

**Формы:** все типы.

---

## Загрузка креатива (Brand Awareness)

Загрузка основного файла креатива. Тип файла зависит от формата адсета:

| Формат | Альт. название | Поле | Тип |
|---|---|---|---|
| FULLSCREEN | Overlay 50% | `video` | Видео |
| PIP | Overlay 15% | `video` | Видео |
| CUSTOM | Custom | `zip` | ZIP-архив |

После загрузки вызывается `verifyAttachment` для серверной валидации. При удалении в режиме редактирования — `deleteAttachment`. Если файл загружен, доступен предпросмотр в диалоговом окне.

Секция **не отображается** для форматов спонсорских сообщений (Chatbot / Text), LEADERBOARD, ADMNG и других. Для форматов спонсорских сообщений основной контент — текст чатбота и ссылка на продукт; загрузка медиафайла не предусмотрена.

**Формы:** Brand Awareness (Overlay 50%, Overlay 15%, Custom).

---

## Баннер (Extension — EXT_BANNER)

Два файла: **banner1** (панель 728×90, макс. 5 МБ) и **banner2** / unit (оверлей 550×310, макс. 10 МБ). Оба файла могут быть **изображениями или видео** (PNG, JPG, GIF, MP4, WEBM) — компонент `ImageOrVideo` автоматически определяет тип при рендере.

Превью показывает `banner1` как горизонтальную панель; при взаимодействии раскрывается `banner2`.

**CSS-редактор** (`EditorBanner`): полноэкранный редактор на базе CodeMirror с подсветкой CSS. Редактирует `model.panel.styles` — произвольный CSS, который инжектируется в `<style>` блок превью. Позволяет полностью переопределить внешний вид: цвета, шрифты, размеры, анимации, позиционирование.

**Формы:** Extension (EXT_BANNER).

---

## Квиз (Extension — EXT_QUIZ)

Интерактивный квиз с настраиваемыми экранами:

- **Приветствие** — заголовок, описание, фоновое изображение/видео
- **Вопросы** — текст, 2–4 варианта ответов, фоновые изображения/видео
- **Результат** — текст, кнопка CTA

Фоны экранов принимают как изображения, так и видео (PNG, JPG, GIF, MP4, WEBM), макс. 5 МБ. Настройки (`FormQuiz`): включение/выключение квиза, показ правильных ответов, пагинация, показ результатов, тексты, цвета.

При создании инициализируется дефолтной структурой (`getDefaultQuiz`) с базовыми стилями (`generateDefaultStyles`).

**CSS-редактор** (`EditorQuiz`): полноэкранный CodeMirror для `model.quiz.styles`. Шаблон стилей содержит заготовки для `.wrapper`, `.welcome-screen`, `.question-screen`, `.result-screen` и др. Все CSS-селекторы должны использовать префикс `._campaign`. Живой предпросмотр (`QuizInstance`) обновляется в реальном времени.

**Формы:** Extension (EXT_QUIZ).

---

## Галерея (Extension — EXT_GALLERY)

Набор слайдов — **изображений или видео** (PNG, JPG, GIF, MP4, WEBM). Каждый слайд загружается отдельно (макс. 5 МБ). Количество слайдов не ограничено на клиенте. Для видео-слайдов карусель учитывает длительность при автоматической прокрутке.

**CSS-редактор** (`EditorGallery`): полноэкранный CodeMirror для `model.gallery.styles`. Карусель в превью имеет фиксированные размеры (236×350), CSS позволяет кастомизировать элементы внутри.

**Формы:** Extension (EXT_GALLERY).

---

## Превью-файл (Extension)

Видеофайл превью для Extension-креатива. Принимает **.mp4** и **.webm**, максимум 2 МБ. Загружается через `ElUpload` в GCS.

**Обязательное поле** — валидация требует наличия превью для сохранения.

**Формы:** Extension (все форматы).

---

## Загрузка креатива (Special Project)

Загрузка основного файла. Тип зависит от формата адсета:

| Формат | Поле | Тип |
|---|---|---|
| SP_CUSTOM | `zip` | ZIP-архив (макс. 10 МБ) |
| Остальные | `video` | Видео (макс. 50 МБ) |

Требования к файлу берутся из **словаря** (`dictStore.campaigns.formatRequirements`), а не из статичных локалей. Серверная валидация (`verifyAttachment`) **не вызывается**.

**Формы:** Special Project.

---

## Ссылка на продукт

URL, на который произойдёт переход с промежуточной страницы (middlepage) после того, как пройдут все проверки и сработают все пиксели. Шаблон промежуточной страницы находится в проекте бэкенда; скрипт, отвечающий за валидацию и пиксели, — в отдельном репозитории вместе с документацией на него.

Два поля: основная (`productUrl.general`) и мобильная (`productUrl.mobile`). Основная ссылка **обязательна** и валидируется как URL. Мобильная — опциональна, валидируется как URL при заполнении.

**Формы:** все типы.

---

## Текст чатбота

Текст, который публикуется в чат трансляции чатботом. Textarea, максимум 150 символов. **Обязательное поле**.

**Формы:** Brand Awareness, Special Project.

---

## QR-код

Чекбокс — показывать ли QR-код во время показа креатива в виджете.

**Формы:** Brand Awareness, Special Project.

---

## Google Ad Tag

Текстовое поле для скрипта Google Ad Manager. Textarea для ввода `scriptCode`.

Отображается **только** если формат адсета равен **ADMNG**.

**Формы:** Brand Awareness (ADMNG).

---

## Пиксели кликов

Список URL-пикселей для отслеживания кликов. Можно добавлять строки; добавление заблокировано, если предыдущая строка пуста. Каждый пиксель валидируется как URL.

**Формы:** все типы.

---

## Скрипт пикселей

Textarea для дополнительного скрипта аналитики (`pixelClicksScripts`).

**Формы:** Brand Awareness, Special Project.

---

## Пиксели показов

Список URL-пикселей для отслеживания показов (`pixelImpressions`). При монтировании компонент гарантирует наличие хотя бы одной строки. Содержит информационный алерт с описанием (HTML из локали).

**Формы:** Brand Awareness, Special Project.

---

## Юридическая маркировка (ERID)

Секция **только для чтения**: отображает идентификаторы ERID при наличии данных в ответе API.

- `legalCompliance.erid.media` → ERID креатива
- `legalCompliance.erid.text` → ERID чатбота

Секция показывается условно — родительская форма проверяет наличие `erid.media` **или** `marker.text`.

**Формы:** все типы — **только редактирование**.

---

## Companion-поля

Модель данных креатива содержит поля `companion.heading`, `companion.text`, `companion.cta`. Эти поля **не отображаются в UI** — пользователь их не редактирует. При создании и обновлении API-адаптеры отправляют фиксированные значения `'done'` для всех companion-полей.

**Формы:** Brand Awareness, Special Project (только на уровне API, не в UI).
